SOFTWARE TEACHER APPRECIATION WEBSITE (thanks Sountharikan!!!!)
=====================================

Open index.html in a browser.

Files:
- index.html   — page content
- styles.css   — styling / responsive layout
- script.js    — animations, terminal, build sequence, counters and confetti

Easy customisations:
1. Search index.html for “Your Software Engineering students” and replace it with your class / names.
2. Edit any of the fake commit messages to add class-specific jokes.
3. Change “Class of 2026” in the footer if needed.
4. The website uses Google Fonts when online, but falls back to system fonts if offline.

No frameworks or libraries are required.
